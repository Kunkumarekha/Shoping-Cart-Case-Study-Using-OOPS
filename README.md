# 🛒 Shopping Cart Management System

A simple **Python-based Shopping Cart Management System** developed using **Object-Oriented Programming (OOP)** concepts.

This project simulates a basic e-commerce shopping cart where users can add products, manage quantities, calculate the subtotal, apply discounts, calculate GST, generate the final bill, remove products, and simulate payment and order confirmation.

---

## 📌 Project Overview

The Shopping Cart Management System is designed to demonstrate how **Python OOP concepts** can be applied to a real-world application.

The project contains two main classes:

- `Item` – Represents a product in the shopping cart.
- `ShoppingCart` – Manages the products and performs cart-related operations.

---

## ✨ Features

- ➕ Add products to the shopping cart
- 📦 Manage product quantity
- 💰 Calculate individual item price
- 🧾 Calculate subtotal
- 🏷️ Apply percentage-based discounts
- 🧮 Calculate GST
- 💵 Calculate final payable amount
- ❌ Remove products from the cart
- 🛍️ Display cart items
- 💳 Simulate payment processing
- 📋 Confirm orders
- 🚚 Display order status
